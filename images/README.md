# Cover images

Drop the two cover files here with **exactly these names**:

| File | Which cover |
|---|---|
| `cover-digital.png` | The **dark** moth cover. Shown at the top of the hub page |
| `cover-print.png` | The **light** moth cover. Shown beside the paperback link |

**The extension can stay `.png` even if the file is really a JPG.** Browsers read the
actual file, not the name.

Portrait, roughly 3:4. Anything from 600px wide up looks fine. Under about 400KB
each keeps the page quick.

Until they are here the page shows a dark placeholder naming the missing path,
so the layout is already correct and nothing looks broken.
